The current Guide index describes guarantees but does not give a reader a coherent account of the actual agent lifecycle. This initiative asks Guide Writer to replace that index with a useful explanation grounded in the implemented control-plane and content contracts.

The page must explain dynamic context queries without persisting query results; validated query definitions and test evidence establish eligibility, while every assignment executes the query again against its authorized current TreeDX ref. It must connect agent definitions and groups, per-model permissions, assignment planning and time safety, operational status and summaries, discussion suspension and continuation, artifact receipts and signals, independent review, target-branch integration, settlement, and residue cleanup.

Success is the exact Guide page at `src/content/knowledge/treeseed-guide/work/agents.md`, linked into the existing Work reader journey, with claims limited to observed backend behavior. Assignment execution alone is not success. The content must validate, be independently reviewed, integrate at an observed target ref, carry a matching artifact receipt, settle, and leave no lease, reservation, workspace, unpublished state, or stale assignment branch.
